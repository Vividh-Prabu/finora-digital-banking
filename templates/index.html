About Finora

Built around your database.

Finora is an academic Digital Banking and Loan Processing System built with Flask and the Firebase Realtime Database. It stores customers, branches, accounts, transactions, loan applications, sanctioned loans and repayments, and enforces the business rules between them.

  • {{ icon('check') }} Duplicate phone, email, Aadhaar and PAN detection
  • {{ icon('check') }} Withdrawals blocked when balance is insufficient
  • {{ icon('check') }} Loan repayments capped at the outstanding amount
  • {{ icon('check') }} CSRF-protected forms and validated input
