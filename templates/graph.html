Connect Neo4j

  1. Create a free instance at neo4j.com/cloud/aura (or run Neo4j locally).
  2. Add NEO4J_URI, NEO4J_USERNAME, NEO4J_PASSWORD and NEO4J_DATABASE to your .env file.
  3. Run pip install -r requirements.txt and python check_neo4j.py.
  4. Restart the app, then click Sync from Firebase here (or run flask --app app sync-graph).

Finora works normally without Neo4j. Once connected, every new record is mirrored automatically.
